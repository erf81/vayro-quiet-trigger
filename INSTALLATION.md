# Installation Guide — Quiet Trigger 2.1.0 by VAYRO

See [docs/INSTALLATION.md](docs/INSTALLATION.md) for the complete guide covering:
- **Option A (Recommended)**: `dist/VAYRO-Quiet-Trigger-Setup-2.1.0-x64.exe` — Complete single-file Windows installer (Photoshop UXP plugin, silent system tray helper, bundled portable Node.js bridge, automatic startup, uninstaller).
- **Option B**: `dist/VAYRO-Quiet-Trigger-Photoshop-2.1.0.ccx` — Official Photoshop UXP plugin only (docked panel without global floating palette).
- SHA-256 checksum verification (`dist/checksums.txt`), unsigned SmartScreen notice, upgrading from ZAU Console 2.0.0 ([docs/UPGRADE.md](docs/UPGRADE.md)), and clean Windows uninstallation.
