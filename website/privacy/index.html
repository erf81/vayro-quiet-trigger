Privacy Policy

Effective Date: November 22, 2026 · Applies to: Quiet Trigger v2.1.0 (Photoshop UXP plugin & Windows companion) and this VAYRO Studio website.

1. Summary — Local-First Operation

Based on a direct audit of the Quiet Trigger v2.1.0 source code (photoshop-plugin/, companion/, and installer/), Quiet Trigger does not collect, transmit, sell, or share personal data, telemetry, analytics, search queries, or Photoshop artwork with VAYRO Studio or any third-party server.

2. Local Storage on Your Device

Quiet Trigger stores configuration and preference files strictly on your local computer under your standard Windows user profile:

  • Photoshop UXP PluginData: %APPDATA%\Adobe\UXP\PluginsStorage\PHSP\<version>\External\com.zau.photoshop.console\PluginData\zau-console-state.json — stores Favorites, Recent Commands, active theme settings, saved custom themes, and local bridge pairing parameters.
  • Windows Companion User Data: %LOCALAPPDATA%\VAYRO\Quiet Trigger\ — stores bridge-session.json (local port and 256-bit session token), theme.json (theme styling only; session credentials are stripped by sanitizeTheme()), and helper-settings.json (selected hotkey and paused state).
  • Upgrade Backup (if upgrading from ZAU Console 2.0.0): Legacy files in %LOCALAPPDATA%\ZAU-Console\ are backed up locally during migration so user preferences are not lost.

3. Local Loopback Bridge & Session Token Handling

  • The local companion bridge (companion/bridge/bridge-server.js) is hardcoded to bind solely to the loopback address 127.0.0.1 (default port 47821) and never accepts external network connections.
  • On first launch, it generates a random 256-bit (64-hex) per-user session token stored only in your private user profile and paired locally with your Photoshop UXP PluginData.
  • All local HTTP and WebSocket messages between the Windows palette and Photoshop UXP require this token and are verified using constant-time comparison (crypto.timingSafeEqual). Tokens are never logged in background mode or included in theme payloads.

4. Network Requests & Third-Party Services

  • Quiet Trigger Plugin & Companion: Zero outbound Internet requests. UXP manifest.json restricts permitted domains exclusively to ws://localhost:47821, http://localhost:47821, ws://127.0.0.1:47821, and http://127.0.0.1:47821. Even the tray menu's "Check for Updates" action opens a local offline version dialog and never phones home.
  • Adobe Photoshop Native AI Commands: Two commands in the registry (Select Subject and Remove Background) trigger Adobe Photoshop's own built-in Adobe Sensei commands via batchPlay. Any cloud processing performed by Adobe Photoshop when you invoke those features is governed by Adobe's own privacy policy and your Adobe account settings, not by Quiet Trigger.
  • This Website (GitHub Pages): This static website loads zero analytics, zero cookies, zero advertising pixels, and zero third-party tracking scripts. The site is hosted on GitHub Pages, and downloads are served from GitHub Releases; GitHub may collect standard server access logs (such as IP address and user agent) under the GitHub General Privacy Statement.

5. Diagnostics & Voluntary Support Reports

Quiet Trigger includes no automatic crash reporter or background diagnostics upload. If you voluntarily open an issue on GitHub, please do not post real session tokens, passwords, or confidential Photoshop artwork.

6. User Data Deletion

Because all application data stays on your local device, you have full control over deleting it at any time:

  1. Uninstall Quiet Trigger via Windows Settings → Apps → Installed Apps and choose not to keep user settings when prompted, or
  2. Manually delete %LOCALAPPDATA%\VAYRO\Quiet Trigger\ and the Photoshop UXP PluginData folder for com.zau.photoshop.console.

7. Contact

For privacy questions or security concerns, visit our Support & Security page or report privately through GitHub Security Advisories on vayrodev/vayro-quiet-trigger.
