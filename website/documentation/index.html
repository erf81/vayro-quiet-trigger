Security Architecture

Zero-Telemetry, Loopback-Only Design

Network Isolation & Constant-Time Auth

  • bridge-server.js binds strictly to 127.0.0.1:47821 — never 0.0.0.0 or external network interfaces.
  • Generates a cryptographically random 256-bit (64-hex) per-user session token stored in %LOCALAPPDATA%\VAYRO\Quiet Trigger\bridge-session.json.
  • Every HTTP header (X-ZAU-Token) and WebSocket upgrade query is validated using crypto.timingSafeEqual; unauthorized requests receive HTTP 401.
  • UXP manifest.json restricts network domains solely to localhost:47821 and 127.0.0.1:47821.

Credential Safety & Command Isolation

  • No session token is ever embedded in the repository, installer, or printed to stdout in --silent mode.
  • sanitizeTheme() strips unknown fields so bridgeToken can never enter theme.json or exported theme data.
  • POST /theme updates styling only and never invokes Photoshop command execution.
  • Repository history is continuously scanned with Gitleaks via GitHub Actions CI.

Complete 98-Command Verification Matrix

Verified on Adobe Photoshop 2025 v26.8.1 (Windows 10 Enterprise x64). We document all 6 interactive GPU workspace and Adobe Sensei limitations transparently rather than claiming universal automation.

Honest Summary of the 6 Documented Limitations
  • 4 Full-Screen GPU Workspaces (Manual Interactive): Lens Blur, Blur Gallery — Field Blur, Liquify, and Camera Raw Filter open full-screen Photoshop GPU workspaces that require interactive user confirmation (OK/Cancel) inside Photoshop's modal UI.
  • 2 Adobe Sensei AI Commands (Cloud / Subject-Dependent): Select Subject and Remove Background invoke Photoshop's native Adobe Sensei models, which depend on active Adobe authentication and a recognizable photographic subject.
