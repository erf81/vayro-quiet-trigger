Code Signing & SmartScreen Verification Notice

Quiet Trigger v2.1.0 is an initial open-source public build without a commercial Authenticode code-signing certificate. Windows SmartScreen may display an "Unknown publisher" notice when running the installer.

Always verify the file's SHA-256 hash against the official checksums.txt before proceeding. See the Installation Guide for the PowerShell verification command.
