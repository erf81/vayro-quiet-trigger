Official community support channels, troubleshooting checklist, and responsible vulnerability disclosure for Quiet Trigger by VAYRO.

Bugs & Feature Requests

GitHub Issues

Open a public issue on the canonical GitHub repository for bug reports, Photoshop compatibility feedback, command requests, or installation help.

  • Include your Quiet Trigger version (e.g. 2.1.0)
  • Include your Adobe Photoshop version and Windows version
  • Describe reproduction steps — never paste real session tokens or private PSD files

Responsible Disclosure

Private Security Reporting

Do not post suspected security vulnerabilities, loopback bridge bypasses, or leaked credentials in public issues or pull requests.

Report security concerns privately via GitHub's Private Vulnerability Reporting (Security Advisories) on vayrodev/vayro-quiet-trigger.

GitHub Security Advisories

Quick Troubleshooting Checklist

  • Global hotkey does not open floating palette: Verify you installed the Complete Windows Installer (.exe), not only the .ccx; verify Adobe Photoshop is the active foreground window; check the Quiet Trigger tray icon to confirm the hotkey is not paused.
  • Floating palette shows Photoshop disconnected: Open Adobe Photoshop and confirm the Quiet Trigger UXP plugin is enabled under Plugins → Quiet Trigger. Restart Photoshop once after first-time installation so UXP loads the paired local bridge token.
  • A command reports a guard message: Some commands require an open document, an unlocked layer, or a non-Text pixel/Smart Object layer. See the 98-Command Matrix for exact requirements.
