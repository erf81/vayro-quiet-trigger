Installation, Verification & Compatibility

Follow the official steps below to install Quiet Trigger cleanly without manually copying files into Adobe-managed plugin folders.

Option A · Recommended

Complete Windows Installer

  1. Download VAYRO-Quiet-Trigger-Setup-2.1.0-x64.exe from the Download page.
  2. Verify its SHA-256 hash using PowerShell (see below).
  3. Run the installer. Because v2.1.0 is currently unsigned, click More info → Run anyway in Windows SmartScreen only after confirming the SHA-256 checksum matches.
  4. Keep both default options checked:
    • Start Quiet Trigger automatically when signing in to Windows
    • Install or upgrade the Quiet Trigger plugin in Adobe Photoshop
  5. Launch Adobe Photoshop 2025 and press Ctrl + Alt + Space.
Option B · Docked Panel Only

Photoshop-Only CCX Package

Choose this option only if you want the docked UXP panel inside Photoshop without the floating Windows palette or global hotkey.

  1. Download VAYRO-Quiet-Trigger-Photoshop-2.1.0.ccx.
  2. Double-click the .ccx file to install via Adobe Creative Cloud Desktop, or install via Adobe's official Unified Plugin Installer Agent (UPIA) CLI:
"C:\Program Files\Common Files\Adobe\Adobe Desktop Common\RemoteComponents\UPI\UnifiedPluginInstallerAgent\UnifiedPluginInstallerAgent.exe" /install "C:\Path\To\VAYRO-Quiet-Trigger-Photoshop-2.1.0.ccx"

Restart Photoshop and open Plugins → Quiet Trigger → Quiet Trigger.

Verify SHA-256 Checksum on Windows (PowerShell)

Get-FileHash .\VAYRO-Quiet-Trigger-Setup-2.1.0-x64.exe -Algorithm SHA256

Upgrading from ZAU Console 2.0.0

Quiet Trigger preserves the internal UXP plugin ID (com.zau.photoshop.console) and panel ID (zauConsolePanel) so upgrades never create duplicate plugins.

  • The installer automatically backs up your Photoshop PluginData JSON, upgrades the plugin via Adobe UPIA, and restores your Favorites and Recents.
  • Legacy settings in %LOCALAPPDATA%\ZAU-Console\ are atomically migrated to %LOCALAPPDATA%\VAYRO\Quiet Trigger\ with a backup copy preserved.

Clean Uninstallation

  1. Open Windows Settings → Apps → Installed Apps, locate Quiet Trigger by VAYRO, and click Uninstall.
  2. The uninstaller stops QuietTriggerHelper.exe and its bundled local bridge, removes startup entries and Start Menu shortcuts, and deletes installed program files.
  3. You are asked whether to also uninstall the Photoshop UXP plugin via Adobe UPIA and whether to keep your saved themes and Favorites (kept by default).
