Frequently Asked Questions

Clear, factual answers about installation packages, Photoshop compatibility, verified commands, security, and upgrades.

What is the difference between the Windows Installer (.exe) and the Photoshop-only CCX (.ccx)?

Complete Windows Installer (VAYRO-Quiet-Trigger-Setup-2.1.0-x64.exe) installs the Photoshop UXP plugin plus the floating Windows WPF command palette, silent system tray helper (QuietTriggerHelper.exe), global Ctrl+Alt+Space shortcut, and bundled portable Node.js loopback bridge.

Photoshop-only CCX (VAYRO-Quiet-Trigger-Photoshop-2.1.0.ccx) installs only the docked UXP panel inside Adobe Photoshop. Installing the .ccx alone does not install the floating Windows companion or global hotkey.

Which Adobe Photoshop versions and operating systems are supported?

Quiet Trigger uses Adobe UXP Manifest v5 and Photoshop API v2 with a declared manifest minVersion of 24.0.0. End-to-end live verification was completed on Windows 10 Enterprise x64 with Adobe Photoshop 2025 v26.8.1.

The floating Windows companion is built for Windows 10 and Windows 11 (64-bit). macOS users who install the standalone .ccx can access only the docked UXP panel (macOS has not yet been live-verified by VAYRO Studio).

Why are 92 of 98 commands live-verified and 6 listed with limitations?

During live QA in Adobe Photoshop 2025 v26.8.1, 92 commands passed full automated state or native dialog verification (67 state-verified + 25 native dialog verified).

The remaining 6 commands work inside Photoshop but have inherent host constraints: 4 open full-screen GPU workspaces (Lens Blur, Field Blur, Liquify, Camera Raw Filter) requiring interactive OK/Cancel inside Photoshop's UI, and 2 (Select Subject, Remove Background) depend on Adobe Sensei cloud/ML models and recognizable photo subjects.

Does Quiet Trigger require global Node.js, AutoHotkey, or Administrator rights?

No. The Complete Windows Installer runs per-user (PrivilegesRequired=lowest, zero UAC prompt) and bundles its own portable Node.js v24.20.0 runtime strictly for the local loopback bridge. No global Node.js, AutoHotkey, or UXP Developer Tool installation is required.

Does Quiet Trigger connect to the Internet or send telemetry?

No. Quiet Trigger makes zero outbound network requests, includes zero analytics or telemetry, and even its "Check for Updates" tray item displays a local offline version dialog. The bridge binds strictly to 127.0.0.1:47821 with 256-bit constant-time session token authentication. See our Privacy Policy for the full code-audited breakdown.

Why does Windows SmartScreen show an "Unknown publisher" notice?

Release v2.1.0 is an unsigned open-source build (no commercial Authenticode certificate was used). Before bypassing SmartScreen, verify the installer's SHA-256 checksum against the official Download page or GitHub Release checksums.txt.

Is Quiet Trigger available on the Adobe Creative Cloud Marketplace?

Not yet. An Adobe Creative Cloud Marketplace listing is being prepared separately under a dedicated Marketplace plugin ID in accordance with Adobe's multi-channel distribution guidelines. Until official Adobe review and approval are completed, download verified builds directly from GitHub Releases.

How does Quiet Trigger handle upgrades from ZAU Console 2.0.0?

Quiet Trigger preserves the independent UXP plugin ID (com.zau.photoshop.console) and atomically migrates settings from %LOCALAPPDATA%\ZAU-Console\ to %LOCALAPPDATA%\VAYRO\Quiet Trigger\ while backing up and restoring your Photoshop PluginData Favorites and Recents.
